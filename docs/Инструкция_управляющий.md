# Инструкция для управляющего

## Доступно
- Создавать заявки (`/заявка`).
- Одобрять/отклонять приём заявки врачом.
- Добавлять вакцинации (`/вакцина`).


## Создание заявок

`/заявка` → направление кнопкой → по шагам: дата выезда, животное, проблема, цена, контакты клиента. Ошиблись — `/отмена`.

## Одобрение и отклонение

1. Диспетчер (или вы, или директор) создаёт заявку — она в рабочем чате.
2. Врач жмёт «Принять».
3. Заявка с деталями появляется в **управленческом чате** — под ней две кнопки:
   - **Одобрить** — контакты клиента уходят врачу в личку.
   - **Отклонить** — заявка снова свободна, может принять любой врач.

Отклонить можно только пока заявка ждёт решения (после одобрения — нельзя). Контактов клиента в самой карточке нет — они видны только врачу, и только после одобрения.

## Вакцинации

`/вакцина` в личке → направление кнопкой → бот спросит: дату вакцинации, вакцину, кого вакцинировали, следующую дату (или «нет»/«-»), контакты клиента. Готово — «Информация добавлена в базу». В чаты не постится.

## Команды

| Команда | Действие |
|---|---|
| `/заявка` | создать заявку |
| `/вакцина` | добавить вакцинацию |
| `/отмена` | прервать заполнение |
| `/помощь` | список команд |
