# Инструкция для диспетчера

Диспетчер создаёт заявки — это единственная его функция в боте.

## Начало

Если ещё не писали боту — откройте его, нажмите «Начать», попросите директора выдать роль «диспетчер».

## Как создать заявку

1. `/заявка`
2. Выберите направление кнопкой (не текстом).
3. Ответьте по шагам:
   - дата выезда (например: `16.07.2026`);
   - животное (вид, возраст);
   - проблема;
   - что оговорено по цене;
   - контакты клиента (имя, телефон).
4. Готово — «Заявка опубликована в рабочем чате».

## Что дальше

Заявка появляется в рабочем чате направления — врачи видят карточку без контактов клиента. Контакты уйдут конкретному врачу в личку только после одобрения управляющим или директором. Вам делать больше ничего не нужно.

Ошиблись — `/отмена` прерывает заполнение.

## Команды

| Команда | Действие |
|---|---|
| `/заявка` | создать заявку |
| `/отмена` | прервать заполнение |
| `/помощь` | список команд |
