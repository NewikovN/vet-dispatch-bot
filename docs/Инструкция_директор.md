# Инструкция для директора

Директору доступно всё: настройка направлений, люди, заявки, вакцинации, отчёты.

## Подключить направление (город)

У каждого направления — два чата в MAX: **рабочий** (врачи, кнопка «Принять») и **управленческий** (детали заявки, кнопки «Одобрить»/«Отклонить»). Без обоих направление не работает.

1. Создайте две группы, например «Выезды — Москва» и «Управление — Москва».
2. Добавьте бота в обе, сделайте его **администратором** в каждой (иначе бот не видит сообщения).
3. В рабочей группе: `/привязать Москва работа`
4. В управленческой группе: `/привязать Москва управление`
5. Название города должно совпадать в обеих командах.

Проверка: `/города` в личке — список направлений и статус их чатов.

## Подключить сотрудника

1. Сотрудник открывает бота и жмёт «Начать».
2. Его ID появится в `/люди`.
3. Выдайте роль: `/роль <id> <роль>`

## Люди

- `/люди` — список сотрудников (ID, имя, роль).
- `/роль <id> <диспетчер|врач|управляющий|директор>` — назначить роль.
- `/уволить <id>` — уволить.

Главного директора разжаловать нельзя.

## Заявки

`/заявка` — направление кнопкой, дальше по шагам: дата, животное, проблема, цена, контакты клиента.

## Одобрение и отклонение

Когда врач жмёт «Принять», заявка с деталями появляется в управленческом чате направления:
- **Одобрить** — контакты уходят врачу в личку.
- **Отклонить** — заявка снова свободна (только пока не одобрена).

## Вакцинации

`/вакцина` в личке → направление кнопкой → дата вакцинации, вакцина, кого вакцинировали, следующая дата (или «нет»/«-»), контакты клиента. В чаты не постится, только в базу.

## Отчёты (только директор)

`/отчет` → тип (Заявки / Вакцины) → фильтр (Полный / По направлению / По дате / Направление + дата) → файл Excel в личку.

Период: `2026.08` (месяц) или `2026.05-2026.08` (диапазон).

## Команды

| Команда | Действие |
|---|---|
| `/люди` | список сотрудников |
| `/роль <id> <роль>` | назначить роль |
| `/уволить <id>` | уволить |
| `/города` | статус направлений |
| `/привязать <Город> работа\|управление` | привязать чат (пишется в самом чате) |
| `/заявка` | создать заявку |
| `/вакцина` | добавить вакцинацию |
| `/отчет` | выгрузить отчёт |
| `/отмена` | прервать заполнение |
| `/помощь` | список команд |
